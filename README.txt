SUBIR A GITHUB PAGES
1. Crea un repositorio público, por ejemplo: pierrevalsaga.
2. Sube todos los archivos conservando la carpeta assets.
3. En GitHub: Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Guarda y espera a que GitHub publique la URL.
7. Después configura pierrevalsaga.com como Custom domain en Settings > Pages.
